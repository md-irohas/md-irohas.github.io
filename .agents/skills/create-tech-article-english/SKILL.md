# 技術ブログ記事の原稿案作成（英語）

日本語記事から、技術ブログ記事の英語版を作成します。

## 資料

英語版の作成にあたっては以下の資料を参考にしてください。

- Codexへの指示: `content/tech/AGENTS.md`
- 原稿執筆のガイドライン: `docs/content-guidelines/tech.md`
- 英語版のテンプレート: `archetypes/tech.en.md`
- 過去記事: `content/tech/` にある直近の英語記事（`index.en.md`）

## 手順

1. ユーザが指定したディレクトリの日本語記事（`index.ja.md`）が作成済みであることを確認します。TODO等が残っている場合や、内容に不明瞭な点がある場合は、ユーザに確認してください。既存の `index.en.md` がある場合は、その内容も確認します。
2. `index.ja.md`をもとに、ガイドラインに従って英語版の原稿案を作成します。
   - 直訳ではなく自然な英語で表現し、原文の主張、意図、文体をできる限り維持します。技術用語には一般的な英語表現を使用します。
   - コード、コマンド、設定値、パス、URL、検証結果は保持します。コメントや説明文を翻訳する場合も、技術的な意味を変えないでください。
   - 検証環境のバージョンや編集履歴を正確に引き継ぎます。技術的な疑義や確認できない点は推測で補わず、ユーザに確認します。
   - Front MatterとShortcodeの書式を維持し、タイトルや説明文等を英訳します。英語版のテンプレートに合わせて `isCJKLanguage` を `false` にします。
3. 原稿案をユーザに提示し、フィードバックを受け取ります。
4. 問題がなければ、原稿案を同じディレクトリの `index.en.md` に書き込みます。
