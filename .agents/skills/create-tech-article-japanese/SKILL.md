# 技術ブログ記事の原稿案作成（日本語）

メモや検証記録から、日本語の技術ブログ記事を作成します。

## 資料

原稿案の作成にあたっては以下の資料を参考にしてください。

- Codexへの指示: `content/tech/AGENTS.md`
- 原稿執筆のガイドライン: `docs/content-guidelines/tech.md`
- 過去記事: `content/tech/` にある直近の日本語記事（`index.ja.md`）

## 手順

1. ユーザが指定したディレクトリのメモ（`index.ja.md`）を確認し、ユーザが記述した内容が正確に読み取れるか確認します。不明瞭な点はユーザに確認します。
2. 内容が技術的に正確かを確認します。確認できない点は推測で補わず、ユーザに確認します。
3. ガイドラインに従って原稿を作成します。
4. 原稿案をユーザに提示し、フィードバックを受け取ります。
5. 問題がなければ、原稿案を `index.ja.md` に書き込みます。
